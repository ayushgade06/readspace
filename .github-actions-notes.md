# GitHub Actions CI Notes

This project uses GitHub Actions for continuous integration.

## Workflow

The CI workflow is defined in `.github/workflows/ci.yml`.

The workflow runs on pushes and on pull requests targeting `main`.

## CI Jobs

The workflow performs the following checks:

1. **Test** — installs backend dependencies and runs the API tests.
2. **Build** — builds the backend and frontend.
3. **Docker validation** — builds the Docker image, validates the Prometheus configuration, starts the containers, and checks the application endpoints.

The Docker validation job runs after the Test and Build jobs pass.

## Viewing Results

Workflow results can be viewed from the **Actions** tab of the GitHub repository.
